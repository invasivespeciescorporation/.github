# Invasive Species Corporation

We research and evaluate biological control agents — microbes that show antagonistic,
inhibitory, toxic, or biocontrol relationships against invasive plant and animal species — and
build the tools our scientists use to find and organize the evidence behind them.

## Repositories

- **[isc_microbe_pipeline](https://github.com/invasivespeciescorporation/isc_microbe_pipeline)**
  — **CrawlNode**, the main research dashboard. Runs literature discovery, antiSMASH chemical
  discovery, and DeepBGC genome mining, and keeps every result in one searchable Evidence
  Database. Start here — its README covers setup end to end and explains every feature.
- **[aisc-deepbgc-pipeline](https://github.com/invasivespeciescorporation/aisc-deepbgc-pipeline)**
  — the containerized genome-mining pipeline that powers CrawlNode's DeepBGC tab. Can also be
  run standalone via Docker/CLI.

## Access
